# GreenCart - E-commerce Platform

GreenCart is a full-featured e-commerce web application built using the MERN stack. It allows users to browse products, manage a shopping cart, and place orders, along with an admin panel for managing products and users.

## Features

- Product listing and search
- Add to cart functionality
- User authentication using JWT
- Order management system
- Admin dashboard for product and user control
- Responsive UI design

## Tech Stack

Frontend:
- React.js
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JSON Web Tokens (JWT)
